Foxglove layouts. `fsds_run.json` works for recorded runs and live views with the default FSDS settings (cameras
`cam1` and `cam2`). `results.json` belongs to the file `scripts/build_results.py` writes: a lap of a race with what
the pipelines found, and a tab per subject with the offline results (see [docs/results.md](../../../docs/results.md)).
Import them in Foxglove via Layouts, Import from file.
